# 시연 고도화 2차: P2 UI (A안) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 실제 웹 UI를 승인된 시안(A안)대로 바꾼다 — 타임라인 레인 머리가 트랙 목록, 오른쪽은 선택한 트랙 상세, 선택하면 영상에서 그 물체의 SAM3 마스크가 강조되고, Solo로 혼자 듣고, 트랙 단위 다시 분리·생성·재생성과 residual 스위치를 쓴다.

**Architecture:** 백엔드는 두 가지만 더한다(트랙→장면 추적 연결, 추적 창에 마스크 RLE). 프런트는 `VideoEditor.tsx`를 얇은 조립 컴포넌트로 줄이고 상단 바·영상 무대·선택 패널·열기 창을 새 컴포넌트로 나눈다. 순수 로직(RLE 디코딩, 선택·하이라이트 대상 계산)은 `web/src/lib/`로 빼서 `node --test`로 검사한다. 스타일은 시안의 CSS를 옮긴다.

**Tech Stack:** React 19, Vite 7, TypeScript, 전역 CSS(`web/src/styles.css`), FastAPI, Pydantic, unittest, `node --test` + vite `ssrLoadModule`.

**Spec:** `docs/superpowers/specs/2026-11-18-demo-upgrade-design.md` §5.4(확정), 시안 `docs/mockups/2026-11-18-demo-ui.html`(+`docs/mockups/shots/`). 시안이 화면의 기준이다.

## Global Constraints

- 시안 `docs/mockups/2026-11-18-demo-ui.html`의 구조·문구·글자 위계·색·모서리·모션 값을 그대로 쓴다. 문구는 영어 sentence case. 생성 방식 표기는 "SelVA w/ SelSync", 분리는 "Separated".
- 새 npm·Python 의존성 금지. 라우터·상태 라이브러리·CSS 프레임워크를 들이지 않는다.
- 1280×720·1440×900에서 페이지·선택 패널 스크롤 없음. 타임라인 `max-height: 38vh`, 넘치면 안쪽 스크롤 + 눈금 고정. ≤900px: 영상 → 선택 패널 → 타임라인, 320px 가로 넘침 없음.
- 글자: 트랙 이름 0.9375rem/600; 상태·주요 버튼·설명 0.8125rem; 배지·Play/Solo·라벨·Seed·Off/On 0.75rem 흐리게(#9aa3b2). 최소 0.75rem. 글자 대비 4.5:1 이상.
- 모서리 컨트롤 6px, 패널 12px. 누름 `scale: 0.96` 150ms ease-out(비활성 제외, 모션 줄이기에서 끔). hover는 `@media (hover: hover)` 안에서만. 포커스 링 흰색 2px.
- 화면당 주(금색) 버튼은 Generate audio 하나.
- 기존 백엔드 API는 깨지 않는다(추가만). 1차 구현의 동작(트랙 재생성, residual, 이벤트 재생성 409 규칙)을 그대로 쓴다.
- 프런트 테스트: `cd web && npx -y node@22 --test tests/*.test.mjs`(호스트 Node 18). 타입: `npx tsc --noEmit`. 백엔드: `uv run python -m unittest discover tests`.

### Task 3: 프런트 순수 로직 — RLE 디코딩·하이라이트·선택

**Interfaces:**
- Produces:
  - `decodeCocoRle(rleJson: string): { width: number; height: number; data: Uint8Array }` — `rleJson`은 `{"encoding":"coco_rle","size":[h,w],"counts":"…"}`. `data`는 행 우선(row-major) `h*w` 0/1. COCO counts는 열 우선(column-major)이다.
  - `objectColor(index: number): string` — 시안의 물체 색 순서(`--c-player`, `--c-enemy`, …)를 따른다; 대상이 없으면 `--c-none` 색.
  - `highlightFor(trackId: string | null, targets: Record<string, string[]>): string[]`
  - `methodLabel(model: GenerationModel): "Separated" | "SelVA w/ SelSync" | "TTS" | "ElevenLabs" | "Hunyuan"`
  - `trackActions(model: GenerationModel, hasAudio: boolean, trackType: string): Array<"re-separate" | "generate-instead" | "regenerate">` — separate → `["re-separate","generate-instead"]`; selsync → `["regenerate"]`(원음이 있으면 `["regenerate","re-separate"]`); speech는 selsync 제외(기존 422 규칙); tts/t2a/v2a → `[]`(이벤트 재생성으로 처리).
  - `statusView(status: TrackStatus | undefined, appRunning: boolean): { label: "Done" | "Generating…" | "Queued" | "Failed" | null; tone: "ok" | "run" | "wait" | "err" | null }` — 레인 머리는 `label !== "Done"`일 때만 보인다.

  COCO 압축 counts 디코딩(시그니처로 정해지지 않는 부분):
  ```ts
  function decodeCounts(s: string): number[] {
    const counts: number[] = [];
    let p = 0;
    while (p < s.length) {
      let x = 0, k = 0, more = 1;
      while (more) {
        const c = s.charCodeAt(p) - 48;
        x |= (c & 0x1f) << (5 * k);
        more = c & 0x20;
        p++; k++;
        if (!more && (c & 0x10)) x |= -1 << (5 * k);
      }
      if (counts.length > 2) x += counts[counts.length - 2];
      counts.push(x);
    }
    return counts;
  }
  // counts: 0의 길이, 1의 길이, … 를 열 우선으로 h*w에 펼친 뒤 row-major로 옮긴다.
  ```
