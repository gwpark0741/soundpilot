# UI 기준 리뷰 (2026-11-18, better-interface)

대상: 불러오기 → SAM3 추적 오버레이 → 사운드 타임라인 → 생성 오디오 → Edit / Regenerate 흐름. 1440, 1024, 800, 720(약 200% 확대), 320 폭.
렌더링: headless Chromium(Playwright), `samples/` 자산과 무음 WAV로 만든 가짜 오디오 산출물. 실제 생성·재생성 실행, 소리 재생, 스크린리더는 확인하지 않았다.
판정: Block (HIGH 9, MEDIUM 6, LOW 묶음은 상한 15개 밖).

사용자 지적 두 가지는 모두 확인됐다.
1. 1440×900에서 첫 항목의 Edit / Regenerate가 y=1050(화면 밖). 스크롤하면 영상과 타임라인이 화면 밖으로 나간다. 2~10번째 항목은 높이 243px 안쪽 스크롤 안에 있다.
2. 개발용 화면처럼 보이는 이유: 소리 레인이 안쪽 스크롤에 숨음, 컨트롤 글자 10~12px, Inter를 지정했지만 불러오지 않음, 타임라인 버튼이 한 글자(`p`, `-`, `e`, `x`), hover·press 상태 없음, 금색 주 버튼 3개와 동작 없는 금색 버튼 1개.
